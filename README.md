# OpenGL 3D Engine

A 3D graphics engine using C++ 17 and OpenGL.

## Project Structure

- `src/`: Source code files (*.cpp)
- `include/`: Header files (*.h, *.hpp)
- `build/`: Build artifacts (generated by CMake)
- `tests/`: Test files
- `examples/`: Example applications using the engine
- `docs/`: Documentation
- `extern/`: External dependencies
- `resources/`: Assets, shaders, textures, models, etc.

## Requirements

- C++17 compatible compiler
- CMake 3.27 or higher
- OpenGL

## Building the Project

```bash
# Clone the repository
git clone <repository-url>
cd OpenGL-3D-Engine

# Create build directory
mkdir -p build
cd build

# Configure and build
cmake ..
cmake --build .
```

## Running the Application

```bash
./bin/OpenGL_3D_Engine
```
